# homebrew-tap

Homebrew formulae for tools by [@raphkoebraam](https://github.com/raphkoebraam).

```bash
brew tap raphkoebraam/tap
```

## Formulae

| Formula | Description |
|---|---|
| [`mirage`](Formula/mirage.rb) | Manage Apple simulators by name, not UDID — a friendly CLI on top of `simctl`. ([repo](https://github.com/raphkoebraam/Mirage)) |

```bash
brew install raphkoebraam/tap/mirage
```

Formulae here are updated automatically by each project's release workflow;
open issues against the project repository rather than this tap.
